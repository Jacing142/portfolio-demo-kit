# Put your project files here

Upload your project into this folder: open it on GitHub, then **Add file > Upload files**.
This file can stay; the tool ignores it.

## What to upload

- **Code**: every file that does the work (scripts, Apps Script `.gs` files, prompt files, settings files).
- **Spreadsheets**: save each sheet as **CSV** (in Google Sheets: File > Download > Comma-separated values).
- **A sample, not everything.** For large sheets, 30 to 50 rows is enough. The tool only needs to
  see the shape of your data: column names, the kind of values, a few unusual cases. Less data
  sent means less risk and lower cost.
- **Size limit**: browser uploads are limited to 25 MB per file. Anything close to that is far
  more than the tool needs.

## What not to upload

- Anything you are not allowed to share, or not allowed to send to an AI provider.
- Full data exports, backups, or files with passwords you still use. If a file contains a live
  API key or password, change that key or password at the source first, then upload.

## Want to try it first?

Leave this folder empty. "1. Scan my project" will use one of the invented examples in `examples/` instead.
