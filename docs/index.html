Your best work is under NDA, so you can't show it.

portfolio-demo-kit turns a private project into a safe public demo you can put in your portfolio: a page people can click through, a diagram of how it works, and a short case study. You decide what stays, what gets replaced with invented data, and what is left out.

How it works

  1. Point it at your project. It reads a copy. Your original files are never changed.
  2. It lists what is sensitive in one table: people's details, your client's know-how, keys and private links. Each row has a suggestion: keep it, replace it with invented data, or leave it out.
  3. You decide. You answer a few questions the code can't: what happens outside the code, what to show off, and what you don't want said in public.
  4. It builds the demo from invented data, running your project's own logic on it where it can. Every result is labelled: a real run, or an example written by Claude.
  5. A leak scan checks every word of the demo against your project, including ten fake "canary" strings planted to catch copied rows. If it finds anything, it fixes it and checks again.
  6. You publish it yourself, after reading it, in a new public repository. Nothing is ever published for you.

Try it (for technical readers)

It is a skill for Claude Code. Install it from inside Claude Code:

/plugin marketplace add Jacing142/portfolio-demo-kit
/plugin install portfolio-demo@portfolio-demo-kit

Or copy the skill folder by hand:

git clone https://github.com/Jacing142/portfolio-demo-kit
cp -r portfolio-demo-kit/plugins/portfolio-demo/skills/portfolio-demo ~/.claude/skills/

Then, in Claude Code, from the cloned folder, ask:

Run the portfolio-demo skill on examples/apps-script-feedback/before

No API key is needed: without one, example outputs are written by Claude and labelled "Illustrative". If ANTHROPIC_API_KEY is set, the project's own prompts are run for real and labelled with the model that answered. Python 3.11 or newer is the only other requirement.

Safety

  • Use it only on work you are allowed to share, and allowed to send to an AI provider. If you are not sure, ask your client first.
  • It reduces risk. It does not guarantee it. Read every word of the demo before you publish it.
  • It never changes your project, never publishes anything, and never keeps keys or passwords, whatever you choose.
